# LOKA – Thrissur Cultural Map

A lightweight React application showcasing cultural locations in Thrissur.  
Features include:
- Explore map with listings and filters
- Community contribution flow (submit, admin review)
- Unified design system (spacing, borders, fonts, responsive layout)
- Accessible UI with focus outlines and proper tap targets
- Static assets stored under `public/images/`

## Project Structure
```
public/
  ├─ favicon.svg
  └─ images/          # all listed photos
src/
  ├─ components/      # UI components (Navbar, Footer, pages, etc.)
  ├─ data/listings.json
  ├─ index.css
  └─ App.jsx
```

## Development
```bash
npm install    # install dependencies
npm start      # run dev server (http://localhost:3000)
npm run build  # create production bundle
```

## Deployment
1. Initialise a remote repository on GitHub.
2. Add the remote and push:
   ```bash
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git branch -M main
   git push -u origin main
   ```
3. Configure GitHub Pages (or your preferred hosting) to serve the `build/` folder.

## Contributing
- Follow the existing design system when adding new components.
- Keep UI‑only changes; never modify data logic or map tiles.
- Run `npm run lint` and ensure no console warnings.
